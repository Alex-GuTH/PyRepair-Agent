# Final Reflection Template

Complete this document after final implementation evidence, review feedback,
and course requirements have been checked. Replace each prompt with a concise,
truthful student reflection supported by repository evidence.

## Problem and Contribution

Prompt: What coding-agent problem did the project address, and what mechanism
was the main contribution?

## Design Decisions

Prompt: Which design alternatives were considered, which were selected or
rejected, and why?

## Agent Workflow

Prompt: How did the specification, plan, worktrees, TDD, verification, and
review process shape the implementation?

## Mechanism Evidence

Prompt: Which mock-LLM tests and demos demonstrate the feedback loop,
guardrails, and stop conditions?

## Security and Safety

Prompt: What credential, path, command, and approval boundaries were
implemented, and what risks remain?

## Evaluation

Prompt: Summarize the actual test, CI, Docker, and manual verification evidence
available at submission time. Do not claim unrun checks passed.

## Limitations and Future Work

Prompt: Identify current limitations, unresolved risks, and the next most
valuable improvements.

## Personal Learning

Prompt: Describe concrete lessons from building, testing, debugging, and
reviewing the harness.
